S4. Scoring, adjudication coverage, and disclosed deviations

  • Scoring and re-administration rules. (i) Scoring: outputs are scored exactly as submitted against the canonical matcher; interpretable-but-non-compliant outputs score as incorrect — Claude Task 3 run 2 embeds the entity name in the type field ("miRNA overexpression"), so 0/20 answers match canonically (its three schema-compliant passes give 60.0); GLM Task 2 passes 3–4 show partial input-field echo (51 and 98 of 193 rows; clean passes reach 95.9–97.9 direction accuracy). (ii) Re-administration: a pass whose outputs are uninterpretable as answers is re-administered once under the identical prompt — GLM Task 1 pass 1 (original capture used a three-column output the two-column parser could not read; the re-administered pass is fully compliant and the original is archived under task1_schema_deviant_2026-10-13/) and GLM Task 2 pass 4 (original capture lost to an API failure, archived under api_failed_2026-10-12/). All re-administrations and schema violations are disclosed.
  • Chain adjudication. Cross-model judging (GPT outputs judged by Claude; Claude outputs judged by GPT; all other systems judged by GPT; no system judged by itself) against unit-level gold mediators, five binary axes per unit. Every system has all four runs adjudicated on both Task 2 (193/193 units each) and Task 3 (20/20 each). Grok Task 3 pass 1's original judgment file was empty (a judging-side capture fault, not a model failure); the 20 units were adjudicated on Oct 16 with the identical judge protocol — evaluation-side only, with no prediction file touched — and the empty file is archived (task3_judgments_empty_2026-10-12.tsv). Mediator-axis false-negative audit: 0/193 Task 2 units name a gold mediator yet score 0.
  • Invalidated capture, re-run (disclosed). GLM Task 2 pass 4 was originally lost to an API failure (Oct 12): the raw capture ended API_FAILED and all 193 rows were harness placeholders. The pass was re-run on Oct 16 under the identical prompt (193/193 parsed, zero empty), re-adjudicated (193/193), and the invalid files are archived under runs_extras/glm/pass4/api_failed_2026-10-12/. A whole-repository integrity sweep confirmed no other pass in any evaluated system contains placeholder rows. The re-run reproduces GLM's partial input-echo behaviour, confirming echo is model output rather than a capture artifact.
  • Task 3 schema policy and sensitivity. The canonical matcher merges method-level variants (bare knockdown accepted for siRNA/shRNA_knockdown gold) but rejects entity-qualified answers as submitted; nine such Claude run-2 answers (chain otherwise passing) move Task 3 joint pass from 49.4% to 51.3% under a semantic-normalization sensitivity view (Claude run 2: 0/20 → 9/20). Strict-schema is the primary view; see Appendix B §B.6.
  • Task composition. Task 3 is a targeted diagnostic subset (20 units, 9 pairs, 6 TFs); several inference targets are not identifiable from the input alone (e.g. agonist vs overexpression), which is why type failures are interpreted as experimental-design knowledge gaps rather than pure reasoning errors.
  • Status. All chain/joint values are preliminary pending blinded human adjudication; packets are archived for that review.

S5. Where mechanistic reasoning breaks: the causal-order axis

Direction-of-change prediction is saturated, and the intervention–outcome link is the strongest adjudication axis for every system (S2). The weakest or second-weakest axis is, without exception, causal order — the requirement that an answer place the transcription factor, the required mediator, and the target gene into an explicit ordered dependency. Systems do not fail because they cannot name entities (the mediator axis is passed nearly as often as the mechanism axis); they fail because the relational structure between the entities they name is absent. Three failure categories are observed.

S5.1 The one-layer default narrative

A single Task 2 unit fails the causal-order axis for all six systems in all 24 adjudicated unit-runs: T2U_0014 (ESR1 → G0S2; perturbation = loss of the target regulatory sites). The gold annotation is chromatin-mediated regulation — the experiment disrupted the ERBS H3K27ac-positive enhancer state by targeted recruitment of SID4X-dCas9-KRAB/SIN3A-HDAC. All six systems predict the correct direction (down) and produce a one-layer narrative in which ESR1 binds DNA directly; none of the 22–24 traces per unit mentions the epigenetic silencing machinery (verified 0 mentions of KRAB/SIN3A/dCas9/H3K27ac across all traces on this unit):

GPT: "Direct cis-regulatory DNA: loss of the G0S2 regulatory site weakens ESR1-linked transcription, lowering G0S2 expression." — Claude: "Perturbing the ESR1-bound regulatory element removes direct enhancer activation of the target, lowering expression." — Gemini: "…perturbation of this binding site eliminates ESR1 recruitment leading to downregulation." — GLM: "…loss_or_reduction of this cis-regulatory site removes the ESR1 enhancer input, so G0S2 decreases." — Grok: "Loss of target cis-regulatory sites prevents ESR1 binding and activation, lowering G0S2." — Biomni: "ESR1 … binds to estrogen response elements (EREs) in the regulatory regions of target genes …"

S5.2 Mediator named, causal role inverted

Units T2U_0022–0023 (ΔNp63 → SAMD9L/ZHX2; perturbation = H2A.Z loss): the gold annotation specifies repressive H2A.Z deposition (loss → gold direction up). Four systems pass the mechanism and mediator axes (each names H2A.Z) and then fail causal order and outcome link by applying the textbook prior that H2A.Z marks permissive chromatin: "H2A.Z loss alters the chromatin state that TP63 needs to activate the target, so expression falls" (Claude; predicted down, gold up). The entity is correct; its position and polarity in the chain are not.

S5.3 Isolated causal-order failures

Exactly five unit-runs in the entire adjudicated pool fail the causal-order axis while passing the other four — all by Gemini, all on chromatin-mediated units where the model names the correct mediator class and direction: "EED/PRC2 acts as a repressive chromatin regulator at the CDX2-regulated target locus, and its loss reduces repressive H3K27me3 marks leading to target gene upregulation." The dependency structure the gold topology requires (TF → required chromatin regulator → transcription) is absent: the mediator is described as a static attribute of the locus, not a node in an ordered causal path. The failure is representational rather than epistemic.

S7. The direct-activation prior (Task 1 pooling)

Pooled over the six systems and four runs (4,104 Task 1 unit-level predictions; GLM Task 1 pass 1 is the re-administered, schema-compliant pass), direct_cis_regulatory_dna accounts for 91.2% of all mechanism predictions (3,743 of 4,104), against a gold frequency of 66.7% (114 of 171 units). On the non-default classes, 82.9% of predictions on chromatin-mediated units, 88.5% on combinatorial units, and 83.3% on regulatory-RNA units are direct-cis. Exact class-level recognition outside direct-cis is rare: 8.5% (chromatin), 10.4% (combinatorial), 10.6% (regulatory-RNA), against 94.5% for direct-cis units. This is not a prompt artifact (prompts are byte-identical across systems and runs) nor a scoring bias (all four classes are counted symmetrically); it is consistent with a default narrative — "TF directly regulates target" — dominating all other mechanistic hypotheses.

S8. Task 3 error taxonomy (post-amendment)

With the disclosed RNA-alias rule in force, the earlier "vocabulary mismatch" failures largely disappear (canonical knockdown on regulatory-RNA units is accepted as inhibition). The remaining Task 3 type errors fall into two verifiable categories:

  • Method inference. For PPARA targets (T3VP_0004/0005/0012) the gold intervention is agonist_activation (ligand agonist, not cDNA overexpression); systems answer "overexpression" — same sign, different experiment, indistinguishable without paper-level knowledge.
  • Precision. For the SMAD3/PTPRK unit (T3VP_0009) the gold is combined_ligand_stimulation (simultaneous NOTCH1 + TGF-β stimulation); systems answer "activation", capturing the sign but not the two-pathway design. A third, borderline case is miR-451 (T3VP_0015), accepted only as genetic_knockout: a "knockdown" answer is genuinely a different experiment and is not rescued by the alias.
