Appendix L — Identifiability and Accepted-Set Analysis for Task 3

Status. Post-freeze analysis addendum (outputs layer). This appendix introduces no new biological labels and does not alter any frozen value. It re-examines the Task 3 answer space as defined by the shipped per-unit accepted intervention sets Ai (evaluation bundle, accepted_intervention_types_json), using the same scoring path as the main tables (canonical matcher plus the disclosed designer-approved entity-conditional RNA alias).

L.1 Accepted-set cardinality

Task 3 contains 20 units over 9 bidirectional pairs. The number of accepted intervention types per unit, |Ai| (after canonicalization), is 1 for 19 units and >1 for 1 units. Where |Ai| > 1 the inverse mapping from the observed direction and perturbed entity back to the intervention that was applied is genuinely one-to-many: more than one intervention is consistent with the benchmark's own labels, and a system cannot be expected to distinguish them from the visible input alone. These units are therefore reported separately throughout this appendix and should not be treated as strict one-to-one inverse-mapping probes.

L.2 Exact-match vs accepted-set accuracy

The shipped scorer reports two layers: exact pre-normalization accuracy (the raw answer string matches a raw gold label verbatim after case/punctuation normalization) and accepted-set accuracy (the canonicalized answer falls in the canonical accepted set). The gap between the two is synonym-rescue mass: answers that are methodologically equivalent to an accepted label but worded outside the raw label set. The main tables use the accepted-set layer, with the RNA alias disclosed in Appendix B; the exact layer is reported here for transparency.

L.3 Identifiability of the inverse task from the visible input

Task 3 shows the model a (TF–gene pair, direction, perturbed entity) triple and asks which intervention was applied to the entity. The task is identifiable from the visible input only if the benchmark's own labels make (entity, direction) determine the accepted set. The map below enumerates every (entity, direction) combination in the task with its accepted canonical union. Every (entity, direction) combination maps to a single accepted canonical set, so no unit is unidentifiable from the input given the labels. The residual non-identifiability is of a second kind and is disclosed in Appendix B.6: the input does not always determine which concrete method within an accepted class was used (e.g. siRNA vs shRNA vs knockout; agonist vs overexpression), and the whitelist settles those cases by construction rather than by inference.

L.5 Reading guidance

(i) Joint-pass values on |Ai| > 1 units should be read as "the system found one of the benchmark-accepted interventions", not "the system recovered the intervention that was performed". (ii) The cardinality split (Table L3) is the strict one-to-one readout. (iii) All values in this appendix are recomputed from the frozen MASTER table and the shipped hidden-label bundle; none modifies or supersedes the main-text Task 3 numbers, which remain the accepted-set (published) layer.
